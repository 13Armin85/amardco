# Amardco Futuristic Website

React + TypeScript + Vite frontend and a separate Node.js backend.

## Run Separately

Start the backend in one terminal:

```bash
cd backend
npm run dev
```

Backend runs at:

```text
http://127.0.0.1:4173
```

Start the frontend from the `frontend` folder in another terminal:

```bash
cd frontend
npm run dev
```

Frontend runs at:

```text
http://127.0.0.1:5173
```

In development, the frontend reads API data from `http://127.0.0.1:4173/api`. In production, the backend serves the built frontend and all API routes from the same origin.

## Production Build

```bash
cd frontend
npm run build
cd backend
npm run start
```

Then open:

```text
http://127.0.0.1:4173
```

## Structure

- `frontend/src` - frontend pages, components, styles, and API client
- `backend` - Node.js server, content data, API routes, and SPA fallback routing
- `frontend/public` - frontend public assets
- `frontend/dist` - production build output generated by Vite
