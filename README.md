# Amardco Futuristic Website

بازطراحی کامل وب‌سایت شرکتی تحلیلگران آمارد نوین با React + TypeScript + Vite.

## اجرا

```bash
npm install
npm run dev
```

Build تولید:

```bash
npm run build
npm run preview
```

## ساختار

- `src/data` — داده‌های شرکت، محصولات و پروژه‌ها
- `src/components` — کامپوننت‌های قابل استفاده مجدد
- `src/pages` — صفحات اصلی، محصولات، پروژه‌ها، درباره، تماس و 404
- `src/hooks/useSEO.ts` — مدیریت title و meta description
- `src/styles.css` — Design System و Responsive UI

## نکته درباره داده‌ها

این نسخه از داده‌های عمومی قابل استناد درباره حوزه فعالیت تحلیلگران آمارد نوین، مجموعه شهرسازی (از جمله نوسازی و درآمد، اصناف و ساختمانی)، راهکار یکپارچه مالی و اداری و اطلاعات تماس عمومی استفاده می‌کند. برای مواردی که داده دقیق عمومی در دسترس نبود (مانند KPI پروژه‌ها، آمار مشتریان، نتایج کمی، ساعات کاری و نام مشتری هر پروژه)، داده ساختگی اضافه نشده است.

## فرم تماس

اعتبارسنجی سمت کلاینت آماده است. برای ارسال واقعی، handler موجود در `Contact.tsx` را به API/Backend دلخواه متصل کنید.
